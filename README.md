# Alex River - Illustrator Portfolio

A clean, minimalist landing page for a professional illustrator.

## 🚀 Deployment Instructions

### Option 1: Netlify (Recommended)
1. Drag and drop the `workspace` folder (or the folder containing these files) onto the [Netlify Drop](https://app.netlify.com/drop) page.
2. Your site will be live instantly!

### Option 2: GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Select the `main` (or `master`) branch as the source.
4. Click **Save**.

### Option 3: Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory.

## 🛠 Local Development
To preview locally:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
